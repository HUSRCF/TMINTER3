# TMINTER3 manuscript

This repository contains the Springer Nature LaTeX working draft for TMINTER3.

The manuscript begins with only the main sections:

- Introduction
- Results
- Discussion
- Methods

Subsections will be added after the scientific narrative and figure order are agreed.

## Compile

```bash
make pdf
```

The original Springer Nature example is retained as `sn-template-example.tex` and
`sn-template-example.pdf`.
